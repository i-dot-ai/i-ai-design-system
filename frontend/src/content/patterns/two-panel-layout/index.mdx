## Pain point

The solution was developed as part of the [education annotation 
tool](https://github.com/i-dot-ai/annotation). The users neededto complete 
a long list of tasks and needed quick access to a large amount of 
contextual information to do this accurately.

Having everything in one long linear flow or separate pages created a confusing
workflow.

## Solution

The solution went for here was to split the task view into 2 pane layout with 
context available in tabs on the left and the task required to be filled out 
on the right:

![screenshot of a two pane layout](/images/screenshot-education.webp)

## Implementation

This can be achieved using the GOV.UK grid system, splitting a row into two
`govuk-grid-column-one-half` columns for the context and task panels:
