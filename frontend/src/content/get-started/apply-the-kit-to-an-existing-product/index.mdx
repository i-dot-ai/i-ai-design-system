Use this when you have a product that predates the kit, and you're
bringing it on.

This is still a work in progress. What follows is how the kit works
today. We're making it easier to install, with npm component packages
coming soon.

## 3. Add component library in language of your choice

Go component by component rather than rebuilding the whole interface at
once. For each one, check whether the kit already covers it:

- if the kit has an as-is or adapted equivalent, replace your version
  with the kit's
- if what you have is a genuine deviation from GOV.UK, that's worth
  recording even if you're keeping it for now
- if what you have doesn't exist in the kit at all, that's a candidate
  for the [kit forum](/get-started/kit-forum), not just a local fix

## 4. Record

Record the components you moved onto the kit, anything you deviated from
along the way, and anything the product needed that the kit still doesn't
have. Take it to the [kit forum](/get-started/kit-forum).
