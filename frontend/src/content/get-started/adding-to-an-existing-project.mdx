This is still a work in progress. This will show how to implement the i.AI Design
Kit as it currently works. We are working on making this easier to implement with
npm component packages coming soon.

## Installation

As this system is built on top of GOV.UK Design System, the first step is to
install govuk-frontend. Here is the recommended way to do that but there are
other options. You can find more information on the [GOV.UK Design System get started guide](https://design-system.service.gov.uk/get-started/production/).

1. ### Install the dependencies

   Run the following command to install Sass and govuk-frontend

   ```sh
   npm install sass govuk-frontend --save
   ```

2. ### Add GOV.UK SASS to your project

   This is the recommended way to adapt the GOV.UK for services not on the
   gov.uk domain. You can read more about this on the [using govuk-frontend without govuk branding guide](https://frontend.design-system.service.gov.uk/using-govuk-frontend-without-govuk-branding/#updating-your-sass-to-remove-branded-elements).

   1. Create a govuk.scss file in your project and copy the following code into it:

      ```scss
      // GOV.UK Frontend, compiled without GOV.UK branding.
      // See: https://frontend.design-system.service.gov.uk/using-govuk-frontend-without-govuk-branding/
      //
      // Change the values below to match your service's branding.
      @use "govuk-frontend" as * with ( // Use a non-GDS Transport font stack (GDS Transport is GOV.UK-branded).
      $govuk-font-family: ("Helvetica Neue", Helvetica, Arial, sans-serif),
      // Set your own brand colour (used e.g. for footer border).
      $govuk-functional-colours: (brand: #16548a));
      ```

   2. If you want to change the brand colour, you can do so by updating the
      **$govuk-functional-colours** variable.

      ```scss
      $govuk-functional-colours: (
        brand: #388E3C
      )
      ```

3. ### Add i.AI adapted stylesheet and javascript file to your project

   Download the stylesheet and javascript file and add it to your projects
   styles and scripts folders respectively.

   <div class="govuk-button-group">
     <a class="govuk-button" href="/i-ai-design-system.min.css" download="i-ai-design-system.min.css">Download i.AI stylesheet CSS</a>
     <a class="govuk-button" href="/i-ai-design-system.min.js" download="i-ai-design-system.min.js">Download i.AI javascript file</a>
   </div>

4. ### Link to the GOV.UK and i.AI css and js files in your project

   Add links to the files added above in the head of your HTML file. This will
   be in the Layout.astro if using Astro. Or frontend/app/layout.tsx if using
   Next.js.

   #### CSS

   Add links to the govuk-frontend css and the i.AI stylesheet css in the head
   of your HTML file. Make sure to put the govuk-frontend css first.

   ```html
   <head>
       ...
       <link rel="stylesheet" href="govuk-frontend.min.css" />
       <link rel="stylesheet" href="i-ai-design-system.min.css" />
       ...
   </head>
   ```

   #### JavaScript

   At the bottom of your HTML file, after the closing body tag, import the
   initAll from govuk-frontend and the initAllIAIDesignSystem from the i.AI
   javascript file.

   ```html
   <body>
       ...
           <script>
               import { initAll } from "govuk-frontend";
               import { initAllIAIDesignSystem } from "../scripts/i-ai-design-system.js";
               initAll();
               initAllIAIDesignSystem();
           </script>
       <body>
   </html>
   ```
