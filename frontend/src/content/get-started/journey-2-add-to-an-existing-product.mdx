---
title: "Add to an existing product"
description:
    For adding a new component or feature to a product that already exists.
---

Use this when you're adding a feature or component to a product that's
already on the kit.

## 1. Confirm the product's brand

Your product already has a brand, set by who it is for. Check it before you
make visual decisions, because the brand decides the theme.

If your product doesn't have a confirmed brand, or if its audience has
changed since it was set, raise it. Don't guess.

## 2. Look before you design

This is where things most often go wrong. Check the kit site before you
draw anything, not after.

Check for:

- the component itself
- an adapted variant of it, such as a subtle input variant
- a pattern that solves the problem differently, such as side navigation
  instead of a longer linear page

## 3. Route

Decide whether you're:

- using an existing kit component as it is
- using an existing component with different content or configuration
- adapting an existing component, which is a deviation
- building something new, which needs the kit forum

The last two both create a record. Know which one you're in before you
start making.

## 4. Make it

Follow style your product and use existing components.

If you're adapting or building new, write down what you needed that the
kit didn't give you, while you're building. You won't remember it
accurately afterwards.

## 5. Check it

Two gates, both required:

- **Behavioural check** — the component does what it should, including
  keyboard operation and screen reader output
- **Human review** — someone other than the person who built it has looked
  at it

## 6. Record

If you adapted a GOV.UK pattern or built something new, take it to the
[kit forum](/get-started/kit-forum).
