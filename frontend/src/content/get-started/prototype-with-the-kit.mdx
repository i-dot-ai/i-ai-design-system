Use the 
[i AI prototyping skill](https://github.com/i-dot-ai/i-ai-design-system/tree/main/frontend/.agents/skills/iai-prototype) 
to prototype with the Design Kit.

It has been designed to read all the components, 
patterns and ways of working that has been set out 
in this Design Kit.

## 1. Download the prototyping skill

Download the zipped prototyping skill from the link below.
<div class="govuk-button-group">
  <a
    class="govuk-button"
    href="/downloads/iai-prototype-skill.zip"
    download="iai-prototype-skill.zip"
  >Download the prototyping skill (.zip)</a>
</div>

## 2. Upload the skill to Claude.ai

Go to [Claude.ai](https://claude.ai/) and add the skill to your account.

1. Go to the **Customize** section in Claude.ai.
    ![Screenshot of the Customize panel in Claude.ai](/images/screenshot-customise-panel.webp)
2. Click **Add** and then **Upload a skill**.
    ![Screenshot of the Add and upload button in Claude.ai](/images/screenshot-add-upload-button.webp)
3. Uplaod the zipped skill you downloaded in step 1 and click **save**.
    ![Screenshot showing a drop zone in Claude.ai](/images/screenshot-add-upload-button.webp)

## 3. Start prototyping

To start using the skill type **/iai-prototype** in the chat window and hit enter.

## 4. Share and contribute your findings

If you run into issues using this skill, you can edit it in your **skills** window in the **customize** section 
of Claude.ai.

If you find something that makes an improvement, you can directly raise a PR here to update the skill and we can review it and merge it for others to benefit too.
