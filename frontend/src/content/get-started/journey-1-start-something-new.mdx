Use this when starting any project in i.AI.
 
## 1. Start with the i.AI Cookie Cutter 

The i.AI Cookie Cutter has been designed with the i.AI Design Kit fully 
integrated. You can follow the instrucitons for setting up a new project 
in the [i.AI Cookie Cutter repository](https://github.com/i-dot-ai/i-dot-ai-cookiecutter). 
It comes with Design Kit components and a `claude.md` file so that agents will 
build with the advice set out in the Design Kit.

## 2. Start with the i.AI Header

For any new project, it is best to start with the [i.AI Header](/components/header). 
This will brand it as an i.AI project. If you need to change later to GOV.UK branding, 
or a particular department, you can change this easily later.

## 3. Work within the i.AI Design Kit

Whether you are building using AI or not, you should work within the i.AI 
Design Kit. It has been designed to free up design decisions so that you can 
focus on important and challenging user experience questions.

## 4. Share any pain points you encounter

If you do encounter issues with the Design Kit, let us know on Slack. Similarly, 
if you encounter design pain points which have not been solved for then you 
can [share your solutions with the Design Kit](/get-started/kit-forum) so that 
others can benefit from them.
