Always use the i.AI colour palette. Reference colours through Sass functions
rather than copying hex values, so your service always uses the latest palette.

## Functional colours

The i.AI Design System has a set of functional colours for essential page
elements. These help apply colours in a way that makes interactions predictable
and consistent to users.

To access these colours, use the `govuk-functional-colour` Sass function. Do not
copy the hex values. For example, use `govuk-functional-colour("brand")` rather
than `#1d70b8`. This means your service always uses the most recent colour
palette whenever you update.

Only use these colours in the context they are designed for. In all other cases,
reference the [web palette](#web-palette) directly.

<CodeSnippet code={`color: govuk-functional-colour("brand"); // not #1d70b8
color: govuk-functional-colour("error"); // error messages`} />

## Web palette

Use the web palette for supporting elements, or in custom components where
appropriate. Access it with the `govuk-colour` function. By default the function
returns the primary variant; use the `$variant` option for tints and shades.

<CodeSnippet code={`color: govuk-colour("blue"); // Primary blue #1d70b8
color: govuk-colour("red", $variant: "tint-25");  // Red tint 25%
color: govuk-colour("blue", $variant: "shade-50"); // Blue shade 50%`} />
