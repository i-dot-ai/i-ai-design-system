title: Styles
description: Styling guidance used across i.AI.
---

This is a collection of styling guidance used across i.AI, covering how to
structure and present applications consistently.

It has been built using the [GOV.UK Design System](https://design-system.service.gov.uk/styles/)
as a starting point. Only when the initial guidance didn't meet the needs of an
app we have built have we adapted it or added new guidance.

Every decision about when styles have diverged from GOV.UK has been documented
in the [principles section](/principles) or can be found in each style's
documentation.
