## Button Variants

### Primary

The primary button is the default button variant. It is to be used when there is one primary action on a page.

If there are multiple primary actions on a page, use the inverse button variant.

<Example component="button" astro="./examples/primary.astro" html="./examples/primary.html" />

### Secondary

The secondary button is to be used when there are two actions, one primary and one secondary. The secondary button should be used alongside the primary button. If there are any more than two actions, use the inverse button variant.

<Example component="button" astro="./examples/secondary.astro" html="./examples/secondary.html" />

## Tertiary

The tertiary button is to be used when there are multiple actions on a page, or the action does not satisfy the above criteria for a primary or secondary action.

<Example component="button" astro="./examples/tertiary.astro" html="./examples/tertiary.html" variant="tertiary" />

## Inverse buttons

Iverse buttons are to replace the primary buttons when on a dark background. The secondary and tertiary buttons are designed to work as usual on a dark background.

<Example component="button" astro="./examples/inverse.astro" html="./examples/inverse.html" variant="inverse" />

## Small buttons

Small buttons are to be used when there is a need for a smaller button, such as in a toolbar or when space is limited. Small buttons can be used with any of the button variants.
