## When to use this component

Use the toggle when a user changes a setting that takes effect immediately, with no submit step, and the setting has a sensible default state of on or off.

## When not to use this component

Do not use the toggle if the change needs a submit button to take effect, if there is no sensible default state, or if the choice is a yes/no answer to a question — use a checkbox or two radio buttons instead.

## Accessibility

### Progressive enhancement

The toggle component renders as a checkbox if js is disabled.
