## Background colour

The header component can be styled with a background colour to match the service.

Please note that the govuk blue colour ("#1d70b8") is reserved for GOV.UK sites only. Read more about [using GOV.UK Frontend without GOV.UK branding](https://frontend.design-system.service.gov.uk/using-govuk-frontend-without-govuk-branding/) .
