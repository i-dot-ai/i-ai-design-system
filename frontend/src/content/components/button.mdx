Buttons have been adapted from the GOV.UK Design System to fit the needs of
i.AI apps. Jump to [button decision record](/decisions-record/buttons) to see
what has changed and why.

## Default buttons

Use the primary button when the action is the main action on the page.

Use the secondary button when the action is a secondary action on the page.
Where you have multiple buttons on the page, the secondary button has been
designed to work to be duplicated multiple times
