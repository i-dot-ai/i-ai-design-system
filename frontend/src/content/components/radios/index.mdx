## Inline

Use inline radios to display the options on a single line where there is enough
space and only two options.

<Example component="radios" astro="./examples/inline.astro" html="./examples/inline.html" />

## Small

Use small radios when the user is unlikely to want to change their answer, or in
a densely populated interface.

<Example component="radios" astro="./examples/small.astro" html="./examples/small.html" />

## When to use this component

Use the radios component when users can only select one option from a list.

## When not to use this component

Do not use the radios component if users might need to select more than one
option. In this case, you should use the [Checkboxes component](/components/checkboxes/)
instead.
