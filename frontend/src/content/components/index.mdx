This is a collection of components that have been used across i.AI that can be
used to avoid having to design bespoke components for each project.

It has been built using the [GOV.UK Design System](https://design-system.service.gov.uk/components/)
as a starting point. Only when the initial design didn't meet the needs of an
app we have built have we adapted them or added new ones.

Every decision about when components have diverged from GOV.UK has been
documented in the [design decisions section](/decisions-record) or can be found
in each component's documentation.
