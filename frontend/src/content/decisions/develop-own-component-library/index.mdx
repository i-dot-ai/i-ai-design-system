## Context

We need a shared set of components so teams do not spend time rebuilding the
same basic ones. Existing third-party libraries would still need accessibility
work and would be hard to hand to another department.

## Decision

We will develop our own component library, based on GOV.UK Frontend and
published as an npm package.
