## Context

We want to stay close to GOV.UK and only move away when there is a real reason.
There is a balance to strike: we want to speed our users up, but not deviate
from GOV.UK when it is not needed. If a departure is recorded as a starting
point, products adopt it by default; if it is recorded as an answer to a
specific problem, products reach for it only when they hit that problem.

## Decision

We will record departures as answers to pain points rather than as starting
places for products. For example, a product should not start with a side
navigation, but can use one if a page is becoming too crowded.
