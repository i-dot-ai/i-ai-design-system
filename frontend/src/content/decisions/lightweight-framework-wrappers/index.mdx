## Context

Products in i.AI at the time of writing are primarily written in React. A 
few use Web components and one product is written in Svelte.

The i.AI frontend team prefer lightweight frameworks to React, so have 
recommended Solid.js as something which has a very similar syntax to React 
but in a much slimmer format.

## Decision

We will provide lightweight, framework-specific wrappers on top of the shared
which i.AI engineers use or are recommended to use. At the time of writing this 
includes: React, Svelte, Solid.js and Web Components
