## Context

Teams work in different frameworks, such as React. Thin wrappers around the
shared components let each team use them in their own framework, while the plain
HTML, CSS and JavaScript stay the single source of truth.

## Decision

We will provide lightweight, framework-specific wrappers on top of the shared
components.
