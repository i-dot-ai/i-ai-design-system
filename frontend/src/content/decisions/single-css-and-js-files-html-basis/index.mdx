## Context

The current GOV.UK Frontend works as a single CSS and JS file which can easily be 
added to any project. The means that, as long as the right html is rendered, 
the component library can be used in any framework.

A brief discussion with the engineers in i.AI also suggested this approach was 
preffered as a means of using a component library.

## Decision

We will hold single CSS and JavaScript files that work with plain HTML as the
basis for the design system.

## Consequences

Allows for very lightweight framework wrappers, see [decision 
010](/decisions-record/lightweight-framework-wrappers)
