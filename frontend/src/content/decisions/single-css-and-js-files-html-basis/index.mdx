## Context

This follows the way GOV.UK Frontend works, with plain HTML, CSS and
JavaScript. Any product can use the styles and behaviour whatever it is built
with, there is one place to update, and it keeps maintenance light.

## Decision

We will hold single CSS and JavaScript files that work with plain HTML as the
basis for the design system.
