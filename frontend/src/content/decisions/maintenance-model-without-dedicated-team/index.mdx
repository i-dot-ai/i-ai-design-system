## Context

The design kit needs to be kept up to date without relying on a dedicated team,
which we do not have. A light, regular process lets it be maintained alongside
people's normal work.

## Decision

We will run a maintenance model that does not require a dedicated team. It uses
a regular open session to review proposals and changes, a set process for
adding components, and a visible status for each component.
